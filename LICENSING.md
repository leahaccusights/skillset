# This is a licensed distribution

The skill files in this package are **stubs**. They carry the name and description
Claude needs to route to a skill, and a loader that fetches the instruction set from
the AccuSights Control Center against a valid entitlement.

Installing this package alone does nothing. The AccuSights installer ships the MCP
tool servers and the license CLI, and without those the skills have nothing to read,
decide on, or write to.

Licenses are one key per machine.

See README.md, DOCTRINE.md, and ARCHITECTURE.md - those are public and describe
exactly what the skillset does and where the tenancy boundary sits.
